# 功能说明

本文档列出“间隔计时”当前已实现的功能、它们的工作方式和已知限制。新增、修改或移除功能时必须同步更新本文件（见 `AGENTS.md`）。

最后更新：2026-10-08 · 版本 1.0.0

## 1. 设定时长

- 数字键盘按“从右往左填充”的方式输入 `时 分 秒`：依次按 `1` `3` `0` 得到 00时01分30秒；最多 6 位（99:59:59）。
- `00` 键一次输入两个 0；删除键删一位，**长按删除键清空**。
- 分、秒位允许超过 59（例如输入 `90` 表示 90 秒），开始时自动换算。
- 快捷预设：30 秒、1 / 3 / 5 / 10 / 25 分钟。
- 已输入的数字高亮显示，未输入的占位 0 显示为次要色。
- 输入框默认填入上一次开始的时长，所以重复使用同一时长只需点“开始”。
- 时长为 0 时“开始”按钮禁用。

## 2. 计时中

- 大号等宽数字显示剩余时间（`MM:SS`，超过 1 小时显示 `H:MM:SS`），四舍五入向上取整，到 `00:00` 时正好结束。
- 环形进度条从满圈顺时针递减；暂停时变为灰色并显示“已暂停”。
- 顶部显示“第 N 轮”。
- 三个操作：**重新计时**（本轮从头开始，轮次不变）、**暂停 / 继续**、**停止**（结束整个会话，回到设定页）。

## 3. 时间到提醒

时间到后进入“时间到”状态，按设置提醒：

| 提醒方式 | 行为 |
|---|---|
| 振动几下（默认，5 下） | 振动 N 下（每下 0.5 秒振 + 0.5 秒停，N 可设 1–30）后自动停止，界面停在“时间到”等待重置 |
| 持续振动 | 一直振动，直到用户点“重置”“关闭提醒”或“停止计时” |
| 同时响铃（可选，默认关） | 播放系统默认闹钟铃声（循环），与振动同时停止 |

- 振动与铃声使用“闹钟”音频用途（`USAGE_ALARM`），在后台、锁屏时也能生效；是否受勿扰模式影响取决于系统的勿扰设置中“闹钟”一项。
- “时间到”界面的操作：
  - **重置**：立即用同样的时长开始下一轮（轮次 +1）。这是主操作，按钮最大。
  - **关闭提醒**：只停止振动/铃声，保持在“时间到”状态（仅在提醒进行中显示）。
  - **停止计时**：结束会话。
- 设置页“试一下”可以预览振动节奏（3 下）。

## 4. 后台驻留

为避免计时在后台被系统杀死或延迟，采用多层保障：

1. **前台服务**（`TimerService`，类型 `specialUse`）：会话进行中（计时、暂停、时间到）一直运行，并显示常驻通知。会话结束（停止）后自动退出，不额外耗电。
2. **精确闹钟**（`AlarmManager.setAlarmClock`）：即使进程被杀、设备处于 Doze 省电状态，也会在到点时唤醒并触发提醒；`setAlarmClock` 不受 Doze 的频率限制，适合频繁重复的短间隔。若用户收回了精确闹钟权限，会退回非精确闹钟，并由服务内计时兜底。
3. **状态持久化**（`TimerStore`）：每次状态变化都同步写入本地；进程被杀后，服务以 `START_STICKY` 重启、或打开应用时，会话从中断处恢复。
4. **权限引导**：设置页列出通知、锁屏全屏提醒（Android 14+）、精确闹钟（Android 12+）、电池优化豁免四项的实时状态，未开启的可一键跳转到系统设置；并提示国产 ROM 需手动允许自启动/后台运行。

## 5. 锁屏操作（无需解锁）

- **常驻通知**在锁屏可见，计时中显示倒计时（系统计时器，逐秒走动）与“暂停 / 重新计时 / 停止”按钮。
- **时间到通知**（高优先级、闹钟类别）在锁屏显示“重置 / 关闭提醒 / 停止”按钮。通知按钮通过广播执行，**锁屏状态下点击即可生效，不需要解锁**。
- **锁屏全屏提醒页**（`AlarmActivity`）：时间到时若屏幕关闭或处于锁屏，会点亮屏幕并在锁屏之上显示大号“重置”按钮，点击后直接开始下一轮并回到锁屏。Android 14 及以上需要在设置中允许“全屏通知”，否则退化为横幅通知（通知按钮仍可用）。

## 兼容性

| 项 | 取值 |
|---|---|
| 最低系统 | Android 8.0（API 26） |
| 目标系统 | Android 15（API 35） |
| 运行时权限 | 通知（Android 13+，首次开始计时时请求） |
| 需用户在系统设置中授予 | 锁屏全屏提醒（Android 14+）、电池优化豁免（推荐） |

## 已知限制

- 手机重启后会话不会恢复（计时基于开机后的单调时钟）。
- 部分国产 ROM 的后台管理会无视前台服务强制清理进程，需要用户手动加入白名单；精确闹钟通常仍能唤醒提醒。
- 关闭通知权限后，锁屏无法显示倒计时与操作按钮，时间到也不会弹出全屏提醒（应用内与振动仍然有效）。
- 界面文字目前只有简体中文。
