# 功能说明

本文档列出“间隔计时”当前已实现的功能、它们的工作方式和已知限制。新增、修改或移除功能时必须同步更新本文件（见 `AGENTS.md`）。

最后更新：2026-10-08 · 版本 1.1.0

## 1. 设定时长

- 屏幕上方是**小时 / 分钟 / 秒**三个格子，**点哪个就选中哪个**（选中的格子有红色粗边框和浅红底色），键盘输入只修改选中的那一项，其他两项保持不变。默认选中“分钟”。
- 在选中的格子里：
  - 第一个数字**替换**原值（选中“分钟”后按 `4` → 04）；第二个数字接在后面（再按 `5` → 45）。输入第一位时，前面的 0 显示为浅色，表示还可以再输一位。
  - 输满两位后自动跳到下一项（小时 → 分钟 → 秒）；分钟、秒第一位输入 6–9 时只可能是个位（`7` = 07），也会直接跳到下一项。到“秒”之后不再跳转，再输入会重新填写秒。
  - 范围：小时 0–99，分钟、秒 0–59。
  - **⌫** 删掉选中项的最后一位（45 → 4，可继续输入），**清零**把选中项设为 00。
- 例：要设 1 小时 30 分 45 秒，点“小时”后依次按 `0 1 3 0 4 5`。
- 快捷预设：30 秒、1 / 3 / 5 / 10 / 25 分钟（会覆盖三项）。
- 默认填入上一次开始的时长，所以重复使用同一时长只需点“开始”。
- 时长为 0 时“开始”按钮禁用。

## 2. 计时中

- 大号等宽数字显示剩余时间（`MM:SS`，超过 1 小时显示 `H:MM:SS`），四舍五入向上取整，到 `00:00` 时正好结束。
- 环形进度条从满圈顺时针递减；暂停时变为灰色并显示“已暂停”。
- 顶部显示“第 N 轮”。
- 三个操作：**重新计时**（本轮从头开始，轮次不变）、**暂停 / 继续**、**停止**（结束整个会话，回到设定页）。

## 3. 时间到提醒

时间到后进入“时间到”状态，按设置提醒：

| 提醒方式 | 行为 |
|---|---|
| 振动几下（默认，5 下） | 振动 N 下（每下 0.5 秒振 + 0.5 秒停，N 可设 1–30）后自动停止，界面停在“时间到”等待重置 |
| 持续振动 | 一直振动，直到用户点“重置”“关闭提醒”或“停止计时” |
| 同时响铃（可选，默认关） | 播放系统默认闹钟铃声（循环），与振动同时停止 |

- **自动亮屏**：时间到时点亮屏幕（屏幕唤醒锁，最长保持 60 秒；提醒结束后按系统的自动锁屏时间熄灭）。这一步不依赖“全屏通知”等权限；如果锁屏提醒页也能弹出，就会显示在锁屏之上。
- 振动与铃声使用“闹钟”音频用途（`USAGE_ALARM`），在后台、锁屏时也能生效；是否受勿扰模式影响取决于系统的勿扰设置中“闹钟”一项。
- “时间到”界面的操作：
  - **重置**：立即用同样的时长开始下一轮（轮次 +1）。这是主操作，按钮最大。
  - **关闭提醒**：只停止振动/铃声，保持在“时间到”状态（仅在提醒进行中显示）。
  - **停止计时**：结束会话。
- 设置页“试一下”可以预览振动节奏（3 下）。

## 4. 后台驻留

为避免计时在后台被系统杀死或延迟，采用多层保障：

1. **前台服务**（`TimerService`，类型 `specialUse`）：会话进行中（计时、暂停、时间到）一直运行，并显示常驻通知。会话结束（停止）后自动退出，不额外耗电。
2. **精确闹钟**（`AlarmManager.setAlarmClock`）：即使进程被杀、设备处于 Doze 省电状态，也会在到点时唤醒并触发提醒；`setAlarmClock` 不受 Doze 的频率限制，适合频繁重复的短间隔。若用户收回了精确闹钟权限，会退回非精确闹钟，并由服务内计时兜底。
3. **状态持久化**（`TimerStore`）：每次状态变化都同步写入本地；进程被杀后，服务以 `START_STICKY` 重启、或打开应用时，会话从中断处恢复。
4. **权限引导**：设置页列出通知、锁屏显示通知、锁屏全屏提醒（Android 14+）、精确闹钟（Android 12+）、电池优化豁免的实时状态，未开启的可一键跳转到系统设置；并提示国产 ROM 需要额外打开的开关。

## 5. 锁屏操作（无需解锁）

- **常驻通知**在锁屏可见：
  - 标题显示**剩余时间**（如“剩余 04:32”，暂停时为“已暂停 · 剩余 01:15”），正文显示“第 N 轮 · 设定 5 分钟”，并有进度条；
  - 计时中由服务每秒刷新一次。熄屏时 CPU 休眠就暂停刷新（不额外耗电），亮屏后立即显示正确时间；
  - 按钮：“暂停 / 继续”“重新计时”“停止”。
- **时间到通知**（高优先级、闹钟类别）在锁屏显示“重置 / 关闭提醒 / 停止”按钮。通知按钮通过广播执行，**锁屏状态下点击即可生效，不需要解锁**。
- **锁屏全屏提醒页**（`AlarmActivity`）：时间到时在锁屏之上显示大号“重置”按钮，点击后直接开始下一轮并回到锁屏。需要下表中的“全屏提醒”相关权限；没有这些权限时，屏幕仍会点亮，可以用锁屏通知上的按钮操作。

### 锁屏显示需要哪些权限 / 设置

| 想在锁屏看到 | 需要 | 在哪里开启 |
|---|---|---|
| 剩余时间、设定时长、暂停/重置按钮（锁屏通知） | ① 通知权限（Android 13+ 为运行时权限）<br>② 本应用的通知允许在锁屏显示（两个类别：“倒计时进行中”“时间到提醒”都不能设为“锁屏不显示”）<br>③ 系统锁屏通知总开关为“显示”（不需要“显示敏感内容”，本应用通知标记为公开） | 设置页“通知”“锁屏显示通知”两项的“去开启”；系统设置 → 通知 → 锁屏通知 |
| 时间到后亮屏 | 无需额外权限（`WAKE_LOCK` 安装时自动授予） | — |
| 时间到后的全屏“重置”页 | ① 通知权限<br>② 全屏通知权限（Android 14+）<br>③ 国产 ROM：“锁屏显示”“后台弹出界面”（小米/红米等） | 设置页“锁屏全屏提醒”的“去开启”；应用详情 → 权限 |

国产 ROM 常见位置：HyperOS/MIUI 在“应用详情 → 通知管理 → 锁屏通知”和“其他权限 → 锁屏显示 / 后台弹出界面”；HarmonyOS/EMUI 在“通知 → 锁屏通知”；ColorOS/OriginOS 在“通知管理 → 锁屏通知”。具体名称以系统为准。

## 已知限制

- 手机重启后会话不会恢复（计时基于开机后的单调时钟）。
- 部分国产 ROM 的后台管理会无视前台服务强制清理进程，需要用户手动加入白名单；精确闹钟通常仍能唤醒提醒。
- 关闭通知权限后，锁屏无法显示倒计时与操作按钮，时间到也不会弹出全屏提醒（亮屏、振动和应用内界面仍然有效）。
- 熄屏期间通知里的剩余时间不刷新（CPU 休眠），亮屏后立即更新；到点提醒由精确闹钟保证，不受影响。
- “锁屏显示通知”检测读取的是本应用通知类别和系统锁屏通知总开关；部分 ROM 自有的锁屏通知开关无法检测，显示“已开启”也可能被 ROM 拦截。
- 界面文字目前只有简体中文。
